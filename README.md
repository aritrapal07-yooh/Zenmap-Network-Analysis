# Network Scanning and OS Detection Using Nmap

## Project Overview

This project demonstrates basic network scanning and operating system detection using **Nmap (Network Mapper)** in a cybersecurity lab environment.

The objective is to understand network host discovery, OS fingerprinting, traceroute analysis, and the interpretation of Nmap scan results.

## Project Objectives

- Understand the fundamentals of network scanning.
- Identify active hosts in an authorized testing environment.
- Perform operating system detection.
- Understand network distance and traceroute results.
- Analyse Nmap scan output.
- Document network observations and security findings.
